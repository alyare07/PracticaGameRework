🎨 3. PIPELINE DE RENDERIZADO Y CAPAS (Z-ORDER)
Para evitar que los textos o el ítem del cursor queden tapados por los fondos de las ventanas, el motor sigue este orden estricto de renderizado:
┌─────────────────────────────────────────────────────────────────────────────────┐
│ CAPA 3: Ítem en Puntero (Plano Superior Absoluto)                               │
│  └─ ItemPuntero.pintar(g, mousePos) -> Dibuja el sprite sobre las coordenadas X,Y│
├─────────────────────────────────────────────────────────────────────────────────┤
│ CAPA 2: Textos y Tooltips Flotantes                                             │
│  ├─ InventarioVault.pintarTooltips(g) -> Cuadro flotante con estadísticas       │
│  └─ Inventario.pintarTooltips(g)      -> Cuadro flotante con estadísticas       │
├─────────────────────────────────────────────────────────────────────────────────┤
│ CAPA 1: Fondos, Marcos y Cuadrículas de Slots                                   │
│  ├─ InventarioVault.pintar(g) -> Fondo gris, marco y celdas del cofre           │
│  └─ Inventario.pintar(g)      -> Si abierto: Ventana completa + Slots           │
│                                  Si cerrado: HUD Inferior (SlotIGU)             │
├─────────────────────────────────────────────────────────────────────────────────┤
│ CAPA 0: Mundo del Juego (Tiles de Terreno, Criaturas, Cofres en el mapa)        │
└─────────────────────────────────────────────────────────────────────────────────┘

4. CICLO DE VIDA Y ROLLBACK DE CONTENEDORES (COFRES / VAULTS)

+-------------------------------------------------------------------------------+
| 1. APERTURA                                                                   |
|   Jugador en rango + Tecla 'E' -> Estado = ABIERTO                            |
|   -> GestorInventario.abrirInventarioTercero(cofre)                           |
|   -> InventarioJugador.hacerVisible()                                         |
+-------------------------------------------------------------------------------+
                                       |
                                       v
+-------------------------------------------------------------------------------+
| 2. CIERRE SEGURO & ROLLBACK (Protección contra duplicaciones/pérdidas)        |
|   Desencadenantes: Jugador se aleja, cierra inventario o presiona 'E'         |
|   -> Estado = CERRADO                                                         |
|   -> GestorInventario.eliminarInventarioTercero(mundo):                       |
|       * ¿El puntero sostenía un ítem sacado de este cofre?                    |
|           ├─ (SÍ) -> Cancela arrastre y devuelve el ítem a su slot de origen  |
|           │          (Si el slot se llenó, lo arroja al suelo del cofre).     |
|           └─ (NO) -> El jugador conserva el ítem que tenía en el cursor.      |
+-------------------------------------------------------------------------------+
