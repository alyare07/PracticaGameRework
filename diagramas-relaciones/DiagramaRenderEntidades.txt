🔄 2. PIPELINE DE ACTUALIZACIÓN LÓGICA (TICK / APS PIPELINE & CULLING)
====================================================================================================

[ GestorPrincipal: Tick Lógico (60 APS) ]
                    │
                    ▼
       [ Mundo.actualizarZonas() ]
                    │
                    ├─► 1. CULLING DINÁMICO DE CÁMARA (AABB Rotado + Zoom + Shake + Margen)
                    │      radioSimulacionX = ceil((CENTROX*cos + CENTROY*sin) / zoom) + shakeX + 2*LADO
                    │      radioSimulacionY = ceil((CENTROX*sin + CENTROY*cos) / zoom) + shakeY + 2*LADO
                    │
                    ├─► 2. CONVERSIÓN A GRILLA DISCRETA AABB
                    │      inicioGridX = Math.max(0, Math.floorDiv(minX, LADO_ZONEBOX))
                    │      finGridX    = Math.min(cantZonasX - 1, Math.floorDiv(maxX, LADO_ZONEBOX))
                    │
                    ├─► 3. ITERACIÓN EN ARREGLO CONTIGUO (Zero Hash Lookup / L1-Cache Friendly)
                    │      ZoneBox zb = ZONAS_ARRAY[gridY * cantZonasX + gridX]
                    │
                    ▼
           [ ZoneBox.actualizar() ]
                    │
                    ├─► ¿Está activo el Editor de Mapas?
                    │    ├─ (SÍ) ──► [ Interrumpir Actualización ]
                    │    └─ (NO) ──► [ Continuar con Entidades ]
                    │
                    ▼
   [ Bucle Directo sobre Colecciones (OBJETOS, CRIATURAS, ITEMS, TPS) ]
                    │
                    ▼
          ¿ente.estaActualizado(Mundo.codAct)?
                    │
             ┌──────┴──────┐
            (SÍ)          (NO)
             │             │
     [ DEDUPLICACIÓN ]     ├─► 1. ente.actualizar() (Lógica / Física / IA)
     [ Ya actualizada]     │        └─ (Si se mueve: setters activan posicionModificada = true)
     [ en este tick  ]     ├─► 2. ente.verificarZoneBox() (Actualización diferida si hubo movimiento)
                           └─► 3. ente.marcarActualizado(Mundo.codAct)

🎨 3. PIPELINE DE RENDERIZADO VISUAL (PAINT / FPS PIPELINE & Y-SORTING)
====================================================================================================

El renderizado desacopla los elementos planos del suelo de los elementos con altura tridimensional,
ordenando estos últimos en tiempo real por su base de apoyo (Pies / Raíces) mediante Insertion Sort:

[ Mundo.pintarZonas(Graphics2D g) ]
                    │
                    ├─► 1. FRUSTUM CULLING VISUAL EXACTO (Compensación de Zoom y Rotación)
                    │      Determina celdas visibles en ZONAS_ARRAY[gy * cantZonasX + gx]
                    │
                    ├─► 2. PASADA 1: ÍTEMS DE SUELO Y RECOLECCIÓN
                    │      │
                    │      ├─► zb.pintar(g) ──► Dibuja Ítems del suelo directamente en capa base
                    │      │
                    │      └─► zb.recolectarEntidadesParaRender(Mundo)
                    │             Si (!ente.estaPintado(Mundo.codPintado))
                    │                ├─► mundo.agregarAColaRender(ente)
                    │                └─► ente.marcarPintado(Mundo.codPintado)
                    │
                    ├─► 3. INCLUSIÓN DEL JUGADOR
                    │      mundo.agregarAColaRender(Globales.JUGADOR)
                    │
                    ├─► 4. ORDENAMIENTO DE PROFUNDIDAD IN-PLACE (Insertion Sort Zero-GC)
                    │      Ordena 'colaRenderEntidades' de menor a mayor 'ente.getPosicionYBase()'
                    │      (Complejidad O(N) lineal sobre lista casi ordenada en < 0.02 ms)
                    │
                    ▼
   [ PASADA 2: DIBUJO SECUENCIAL EN ORDEN Z PERFECTO ]
   for (int i = 0; i < cantEntidadesEnCola; i++) {
       colaRenderEntidades[i].pintar(g);
       colaRenderEntidades[i] = null; // Limpieza inmediata de punteros para el GC
   }

únicamente si la entidad ejecutó un cambio real en sus coordenadas.

🧩 5. MECANISMO DE DEDUPLICACIÓN DIRECTA POR FLAGS EN REGISTRO CPU
====================================================================================================

Escenario: Un Ogro (Criatura grande de 64x64 px) solapa simultáneamente 4 celdas espaciales.

           Grilla Plana 1D                     Procesamiento Lógico en Tick #1040
     +--------------+--------------+
     |              |              |           Mundo.getCodAct() = 1040
     |   ZONAS[0]   |   ZONAS[1]   |
     |        ┌─────┼─────┐        |           1. Mundo procesa ZONAS[0]:
     +--------│  O  G  R  │O-------+              - Encuentra al Ogro.
     |        └─────┼─────┘        |              - Ogro.estaActualizado(1040) -> FALSE (valía 1039).
     |   ZONAS[w]   |  ZONAS[w+1]  |              - Ejecuta Ogro.actualizar().
     |              |              |              - Ogro.marcarActualizado(1040).
     +--------------+--------------+
                                               2. Mundo procesa ZONAS[1], ZONAS[w] y ZONAS[w+1]:
                                                  - Encuentran al mismo Ogro.
                                                  - Ogro.estaActualizado(1040) -> TRUE.
                                                  - SE OMITE AL INSTANTE (1 ciclo de CPU, 0 Maps).
                                                  - Resultado: Lógica ejecutada exactamente 1 VEZ.


====================================================================================================
⚡ 6. ESPECIFICACIONES DE RENDIMIENTO Y OPTIMIZACIONES ZERO-GC (ACTUALIZADO)
====================================================================================================

1. Grilla Plana Unidimensional (ZoneBox[] ZONAS_ARRAY):
   - Mapeo aritmético directo en O(1): indice = (gridY * cantZonasX) + gridX.
   - Elimina la sobrecarga de tablas Hash, cálculo de buckets y colisiones.
   - Datos contiguos en memoria: maximiza el aprovechamiento de la memoria caché L1/L2 de la CPU.

2. Eliminación Total de Clases Envoltorio (RenderEntidad y MapRender purgados):
   - 0 objetos intermediarios instanciados por cada entidad en el mapa.
   - Al spawnear 10.000 entidades, se ahorran más de 30.000 objetos en el Heap (envoltorios, sets, entries).

3. Deduplicación O(1) Pura por Puntero Local en Ente:
   - 'codUltimaActualizacion' y 'codUltimoPintado' residen dentro del propio objeto Ente.
   - Elimina miles de consultas 'IdentityHashMap.get()' por frame en render y actualización.

4. Patrón Dirty Flag Diferido (posicionModificada):
   - Entidades estáticas (árboles, casas, rocas, cofres) ejecutan 0 verificaciones espaciales tras la carga.
   - Movimientos diagonales o físicas multi-paso solo sincronizan la grilla 1 vez por tick.

5. Corrección de Asignaciones Ocultas en Heap (Zero-GC):
   - 'Objeto.getArea()' y 'Complemento.getArea()' reutilizan 'AREA_ENTE_RETORNO' sin crear 'new Rectangle()'.
   - Remoción segura de proyectiles y partículas mediante iteración inversa (i--) eliminando saltos de frames.

6. Renderizado con Y-Sorting In-Place:
   - Reutilización continua del arreglo 'colaRenderEntidades' con auto-expansión dinámica.
   - Ordenamiento por profundidad con Insertion Sort en tiempo lineal O(N) para listas casi ordenadas.
