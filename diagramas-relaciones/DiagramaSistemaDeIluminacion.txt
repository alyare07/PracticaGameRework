3. DIAGRAMA DE FLUJO: PIPELINE GRÁFICO (RENDERIZADO)
Este flujo ocurre en GestorJuego.pintar(), dividiendo la pantalla en 3 capas estrictas:

=========================================================================
 === FASE 1: CAPA DE MUNDO (CON ZOOM, TEMBLOR Y ROTACIÓN)
 =========================================================================
   [ Mapa / Terreno ]  -----> Dibuja tiles y suelo.
   [ Entidades Y-Sort] -----> Dibuja árboles, cofres, monstruos y Jugador.
   [ Partículas ]      -----> Dibuja chispas, sangre y humo.
   [ Textos Daño ]     -----> Dibuja números de combate flotantes.

 =========================================================================
 === RESTAURACIÓN DE MATRIZ (Regreso a Espacio de Pantalla 1:1 Fijo)
 =========================================================================
                               |
                               v
 =========================================================================
 === FASE 2: CAPA DE ILUMINACIÓN Y NOCHE [ GestorLuz.pintar(g) ]
 =========================================================================
                               |
                               v
            ¿ColorAmbiente es transparente (Alpha == 0)?
                 /                           \
               SÍ                             NO
               /                               \
     [ 0% Costo de GPU ]            [ Inicia Render del Lightmap ]
    (Es mediodía soleado:                          |
     Retorna de inmediato)                         v
                              1. VACIADO DE MEMORIA VRAM:
                                 gLight.setComposite(AlphaComposite.CLEAR);
                                 gLight.fillRect(0, 0, 640, 360);
                                                   |
                                                   v
                              2. ESTAMPAR LA OSCURIDAD AMBIENTAL:
                                 gLight.setComposite(AlphaComposite.SRC_OVER);
                                 gLight.setColor(colorAmbiente);
                                 gLight.fillRect(0, 0, 640, 360);
                                                   |
                                                   v
                              3. PERFORAR AGUJEROS DE LUZ:
                                 gLight.setComposite(AlphaComposite.DST_OUT);
                                 Para cada luz activa:
                                   a) Proyecta (X, Y) con Cámara, Zoom y Giro.
                                   b) Escala radio de luz según Zoom.
                                   c) Dibuja la textura de halo pre-horneada.
                                   *(El blanco del halo borra la sombra)*
                                                   |
                                                   v
                              4. ESTAMPAR LIGHTMAP SOBRE LA PANTALLA:
                                 g.drawImage(lightmap, 0, 0, null);

 =========================================================================
 === FASE 3: CAPAS DE INTERFAZ / HUD (NO SE OSCURECE JAMÁS)
 =========================================================================
   [ Barras de Vida/Maná ] ---> 100% brillante y legible sobre la noche.
   [ Inventarios y Slots ] ---> 100% visible sin sombras.
   [ Textos de Debug ]    ---> 100% visible.
