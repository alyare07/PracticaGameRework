3. DIAGRAMA DE FLUJO: PIPELINE GRÁFICO (RENDERIZADO EN 4 FASES)

================================================================================
 === FASE 1: CAPA DE MUNDO [ GestorJuego -> bufferMundo (VRAM 1:1) ]
 ================================================================================
   [ Mapa / Terreno ]  -----> Dibuja tiles y suelo.
   [ Entidades Y-Sort] -----> Dibuja árboles, cofres, monstruos y Jugador ordenados.
   [ Partículas Mundo] -----> Dibuja chispas, sangre y efectos de combate.
   [ Textos Flotantes] -----> Dibuja números de daño.

 ================================================================================
 === PROYECCIÓN DE MATRIZ DE CÁMARA (Zoom, Temblor y Rotación)
 ================================================================================
   g.drawImage(bufferMundo, ...) -> Proyecta el mundo a pantalla con la lente activa.
   Restauración LIFO de matriz   -> Regreso a Espacio de Pantalla Lógico (640x360).

 ================================================================================
 === FASE 2: CAPA ATMOSFÉRICA [ GestorClima.pintar(g) ]
 ================================================================================
   [ Sombras de Nubes] -----> Nubes diurnas (512px) con Smoothstep (se apagan de noche).
   [ Capa de Niebla ]  -----> Bruma desplazada por viento (atenuada en la noche).
   [ Partículas Clima] -----> Lluvia, Nieve, Hojas, Ceniza, Esporas o Arena.

 ================================================================================
 === FASE 3: CAPA DE ILUMINACIÓN Y SOMBRAS [ GestorLuz.pintar(g) ]
 ================================================================================
   ¿Alpha de Oscuridad == 0 y sin relámpagos activos?
        /                           \
      SÍ                             NO
      /                               \
 [ 0% Costo de GPU ]        1. VACIADO DE VRAM:
(Mediodía despejado:           gLight.setComposite(CLEAR);
 Retorna de inmediato)         gLight.fillRect(0, 0, 640, 360);
                                              |
                                              v
                            2. ESTAMPAR OSCURIDAD AMBIENTAL:
                               gLight.setComposite(SRC_OVER);
                               gLight.setColor(colorAmbienteCalculado);
                               gLight.fillRect(0, 0, 640, 360);
                                              |
                                              v
                            3. PROYECCIÓN FOCAL DE CÁMARA:
                               centroMundoCamX = camX + (enteAncho / 2.0);
                               centroMundoCamY = camY + (enteAlto / 2.0);
                               (Elimina desfase de +16px; alinea luz y sprite)
                                              |
                                              v
                            4. PASE A: PERFORACIÓN DE PENUMBRA (DST_OUT):
                               Para cada luz visible en pantalla:
                                 - Rota con pivote central (cx, cy) si es cono.
                                 - Dibuja 'texturaMascaraAlphaHD' o Cono HD.
                                 *(El blanco perfora y transparenta la sombra)*
                                              |
                                              v
                            5. PASE B: TINTE DE COLOR (SUNLIGHT WASHOUT):
                               IndiceComposite = (alphaSombra / 200.0) * 10
                               gLight.setComposite(COMPOSITES_TINTE[0..10]);
                                 - Noche/Cuevas: Tinte cálido/arcano al 100%.
                                 - Mediodía soleado: Tinte desvanecido al 0%.
                                 - Dibuja 'texturaHaloColor' sobre el agujero.
                                              |
                                              v
                            6. DESTELLO BLANCO DE RELÁMPAGO (Opcional):
                               Si hay rayo activo, estampa blanco translúcido.
                                              |
                                              v
                            7. ESTAMPAR LIGHTMAP SOBRE LA PANTALLA:
                               g.drawImage(lightmap, 0, 0, null);

 ================================================================================
 === FASE 4: CAPA DE INTERFAZ / HUD (100% INMUNE A SOMBRAS Y NIEBLA)
 ================================================================================
   [ Barras Vida/Maná ] ---> 100% brillante y legible sobre la noche.
   [ Inventarios/Slots] ---> 100% visible sin sombras.
   [ Textos de Debug  ] ---> 100% visible.


4. GUÍA DE USO Y COMUNICACIÓN EN GAMEPLAY (CASOS DE USO)

--------------------------------------------------------------------------------
Caso A: Transición y Carga de Mapas (Limpieza Total de Luces)
--------------------------------------------------------------------------------
[ GestorJuego.cargarMapa() ]
             |
             +--> Globales.GESTOR_LUZ.apagarTodasLasLuces(); // Evita luces fantasma
             +--> Carga escenario y spawns...
             +--> Globales.GESTOR_LUZ.agregarLuzAnclada(JUGADOR, LINTERNA_CONICA);

--------------------------------------------------------------------------------
Caso B: Creación, Anclaje y Calibración de Linternas
--------------------------------------------------------------------------------
// Luz fija en muro (Antorcha de pared):
Globales.GESTOR_LUZ.agregarLuzEstatica(x, y, TipoLuz.ANTORCHA);

// Linterna cónica anclada al Jugador con calibración de altura:
FuenteLuz linterna = Globales.GESTOR_LUZ.agregarLuzAnclada(
    Globales.JUGADOR, TipoLuz.LINTERNA_CONICA, 120.0);
linterna.setOffset(0.0, -4.0); // Ajusta la luz al pecho/cabeza del sprite

// En Jugador.actualizar():
linterna.orientarSegunDireccion(Globales.JUGADOR.getDireccion());
// O apuntando hacia el ratón:
// linterna.orientarHaciaPunto(RATON.getXMundo(), RATON.getYMundo());

--------------------------------------------------------------------------------
Caso C: Inteligencia Artificial y Mecánicas de Sigilo (Stealth Queries)
--------------------------------------------------------------------------------
// En Criatura / Enemigo.actualizarIA():
boolean iluminado = Globales.GESTOR_LUZ.isPosicionIluminada(
    Globales.JUGADOR.getPosicionXInt(), 
    Globales.JUGADOR.getPosicionYInt()
);

double rangoDeteccion = iluminado ? 320.0 : 90.0; // 70% menos visión en sombras

--------------------------------------------------------------------------------
Caso D: Explosiones, Granadas y Hechizos (Flashes Temporales)
--------------------------------------------------------------------------------
// Al detonar una granada o bola de fuego en (x, y):
// Crea un flash de 180px con decaimiento cuadrático en 0.35 segundos
Globales.GESTOR_LUZ.dispararFlashPosicional(x, y, 180.0, 0.35);

--------------------------------------------------------------------------------
Caso E: Modificadores de Visión y Pociones
--------------------------------------------------------------------------------
// El Jugador bebe Poción de Visión Nocturna (+60% de campo visual):
FuenteLuz luz = Globales.JUGADOR.getLuzAsignada();
if (luz != null) {
    luz.setMultiplicadorRadio(1.60);
}

--------------------------------------------------------------------------------
Caso F: Control del Reloj Solar y Descanso
--------------------------------------------------------------------------------
// El Jugador duerme en una posada:
Globales.GESTOR_LUZ.getCiclo().irAAmanecer(); // Salta a las 06:30

// Pausar el reloj durante cinemáticas o menús:
Globales.GESTOR_LUZ.getCiclo().pausarTiempo();
Globales.GESTOR_LUZ.getCiclo().reanudarTiempo();
